# RR1 Timer Protos

Protocol buffer schemas for RR1 timer messages.

Generated protobuf-c files are produced by GitHub Actions and packaged as an
artifact named `rr1-messages-generated`.

The generated artifact is shaped to overlay the ESP-IDF `rr1_messages`
component:

- `timer.pb-c.c`
- `timestamp.pb-c.c`
- `include/timer.pb-c.h`
- `include/google/protobuf/timestamp.pb-c.h`
